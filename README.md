 AI Resume Screening Platform

An AI-powered resume screening and candidate matching platform designed to help recruiters efficiently analyze resumes and identify the most relevant candidates based on job requirements.

 Features

- 🔐 Secure HR authentication
- 💼 Create and manage job positions
- 📄 Upload PDF/DOCX resumes
- 🤖 AI-powered resume analysis
- 🎯 Candidate matching based on job requirements
- 👤 Candidate profiles and detailed analysis
- 📊 Recruiter dashboard

 Tech Stack

Frontend: React, Tailwind CSS  
Backend: FastAPI, Python  
Database: PostgreSQL  
AI: Google Gemini, LangChain  
Authentication: JWT
